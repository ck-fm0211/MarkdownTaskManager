## 実機での手動確認（10 分程度、ダミーデータで）

準備: OneDrive 内にテスト用の `data` フォルダーを作り、`examples/kanban.md` と `examples/archive.md` をコピーする
（**実業務データでは行わない**）。B に配備した `task-manager.html` を Edge で開き、`data` を選ぶ。

1. **日本語表示**: 画面が日本語であること（英語なら右上で「日本語」を選ぶ）。タスクを 1 件、日本語のタイトル・タグ（`#経理`）・
   サブタスクで作成 → メモ帳で `kanban.md` を開き、内容が書かれていること → 🔄 で再読込しても同じ表示であること。
2. **外部変更の保護**: ブラウザーを開いたまま、メモ帳で任意のタスクのタイトルを変えて保存 → ブラウザーに戻る
   （未編集なら「外部で行われた変更を読み込みました」と表示され、変更が反映される）。
3. **競合**: ブラウザーでタスク編集画面を開いたまま、メモ帳でファイルを変更・保存 → ブラウザーで「保存」
   → 「⚠️ 競合」になり、メモ帳の変更がファイルに残っていること。「未保存分をダウンロード」でファイルが保存されること。
   「ディスクから再読込」でメモ帳の変更が表示されること。
4. **アーカイブ**: 完了タスクをアーカイブ → `archive.md` に追加、`kanban.md` から削除されていること → アーカイブ画面で
   `TASK-` の ID で検索して見つかること → 復元できること。
5. **プロジェクト切替**: `archive.md` のない別フォルダー `data2`（`kanban.md` だけ）を開き、タスクをアーカイブ →
   `data2` に `archive.md` が作られ、`data` の `archive.md` が変わっていないこと。
6. **OneDrive**: 上記の後、エクスプローラーで `data` の OneDrive アイコンが同期済み（緑のチェック）になること。
   OneDrive の「バージョン履歴」で `kanban.md` の過去版が見られること。
7. **配備**: `npm run deploy:dry` → `npm run deploy` → `D\html\` に旧版が退避され、`C` のファイルの更新日時が変わっていないこと。
8. **バックアップ**: `npm run backup` → `D\source\` に ZIP ができ、`npm run restore:verify -- <ZIP>` が `[復元確認 OK]` になること。
9. **文字コード**: テスト用の `data` で、Windows PowerShell 5.1 から `Add-Content archive.md "メモ"` を実行 → ブラウザーで 🔄 →
   アーカイブがエラー表示で止まり（「UTF-8 ではありません」）、`archive.md` が書き換わらないこと。
   `npm run tasks -- check --dir <data>` が `UTF-8 ではありません` を表示すること。メモ帳で UTF-8 で保存し直すと元に戻ること。
